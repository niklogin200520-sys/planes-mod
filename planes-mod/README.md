# Planes Mod для Minecraft 1.21.1

Мод добавляет 5 различных самолётов в ванильном стиле, на которых можно полностью летать!

## Самолёты в моде

1. **Биплан** - Самый простой деревянный самолёт. Медленный, но лёгкий.
2. **Истребитель WWI** - Боевой самолёт Первой Мировой войны. Быстрее биплана.
3. **Истребитель WWII** - Мощный истребитель Второй Мировой войны.
4. **Реактивный истребитель** - Современный реактивный истребитель. Самый быстрый!
5. **Современный самолёт** - Пассажирский самолёт. Надёжный и комфортный.

## Как установить

### Требования
- Minecraft 1.21.1
- Fabric Loader 0.15.11 или выше
- Java 21 или выше

### Шаг 1: Загрузить Fabric Installer
1. Скачай Fabric Installer для твоей ОС с https://fabricmc.net/use/installer/
2. Запусти установщик
3. Выбери версию 1.21.1
4. Нажми "Install"

### Шаг 2: Скомпилировать мод

1. **На Windows (PowerShell):**
```bash
cd planes-mod
gradlew.bat build
```

2. **На Linux/Mac (Terminal):**
```bash
cd planes-mod
chmod +x gradlew
./gradlew build
```

### Шаг 3: Поставить мод в Minecraft

1. Открой папку `.minecraft/mods` 
   - **Windows**: `%AppData%\.minecraft\mods`
   - **Linux**: `~/.minecraft/mods`
   - **Mac**: `~/Library/Application Support/minecraft/mods`

2. Скопируй файл из `planes-mod/build/libs/planes-mod-1.0.0.jar` в папку `mods`

3. Запусти Minecraft с профилем Fabric 1.21.1

## Как использовать

После установки мода, самолёты появятся в креативном меню в разделе "Miscellaneous".

### Как летать

1. Дай себе предмет самолёта командой (или найди в творчестве):
```
/give @s planes:biplane
```

2. Нажми **Правую кнопку мыши** с предметом самолёта в руке
   - Самолёт спавнится под тобой
   - Ты автоматически займёшь сиденье пилота

3. **Управление полётом:**
   - **W/↑** - Летать вперёд
   - **S/↓** - Летать назад
   - **A/←** - Лететь влево
   - **D/→** - Лететь вправо
   - **Space/Прыжок** - Лететь вверх
   - **Shift/Крич** - Лететь вниз
   - **Мышь** - Поворачивать самолёт

4. Левая кнопка мыши - Выход из самолёта

## Команды

```
# Получить конкретный самолёт
/give @s planes:biplane
/give @s planes:fighter_ww1
/give @s planes:fighter_ww2
/give @s planes:jet_fighter
/give @s planes:airliner

# Дать стопку (64 шт)
/give @s planes:biplane 64
```

## Проблемы и решения

**Самолёт не спавнится:**
- Проверь, что мод правильно установлен в папку mods
- Перезагрузи Minecraft
- Убедись, что используешь Fabric версию 1.21.1

**Самолёт падает:**
- Это нормально! Самолёту нужна горизонтальная скорость, чтобы лететь
- Разгонись вперёд и потом поднимайся вверх

**Низкая FPS:**
- Уменьши расстояние рендеринга в настройках видео
